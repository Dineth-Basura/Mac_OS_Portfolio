## Overview
A full-stack Java application for gym operations and member management.

## Features
- Authentication and user access control.
- Member registration and profile management.
- Trainer assignments.
- Membership and payment processing.
- Attendance tracking and administrative dashboards.

## Architecture
Spring Boot exposes RESTful backend services and integrates with MySQL. Maven handles the Java build workflow.
