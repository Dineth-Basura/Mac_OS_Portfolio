## Overview
A JavaScript e-commerce application for browsing and purchasing books, with inventory management for administrators.

## Features
- Book browsing and search.
- Shopping cart and purchasing workflows.
- Inventory management.
- JWT-based authentication.

## Architecture
A React interface connects to a Node.js and Express REST API, with MongoDB for data storage and JWT for authentication.
