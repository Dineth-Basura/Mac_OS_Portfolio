## Overview
A cross-platform graphical tool for password strength analysis, secure password generation, and actionable recommendations.

## Technical approach
The application uses zxcvbn for strength analysis and Fisher-Yates shuffling in its password generation workflow.

## Features
- Real-time strength analysis.
- Cryptographically secure password generation.
- Security recommendations and policy-aware password suggestions.
