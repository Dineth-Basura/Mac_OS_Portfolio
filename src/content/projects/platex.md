## Overview
An AI-powered system for detecting and recognizing vehicle license plates using deep learning and computer vision.

## Technical approach
YOLOv12 provides object detection, PaddleOCR performs optical character recognition, and OpenCV supports image processing. Flask is included in the application stack.

## Architecture
Vehicle image → plate detection → detected plate region → OCR → recognized characters.
