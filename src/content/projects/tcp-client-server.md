## Overview
A networking application demonstrating low-level communication and integration between two programming languages.

## Technical approach
A C server and Python client communicate over TCP sockets. The application implements bidirectional communication and server-side logging.

## Features
- Cross-language client-server communication.
- Server-side logging.
- Automated compilation through Makefiles.
